# hehes

Magic Bus landing page built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS v4**.

## Scripts

- `npm install` – install dependencies
- `npm run dev` – start development server
- `npm run build` – production build
- `npm run preview` – preview production build
- `npm run lint` – run ESLint

This project is wired to the GitHub repository `shashankpatil125/hehes` and serves as a demo landing page inspired by Magic Bus.
